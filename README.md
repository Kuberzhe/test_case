# test_case
Для запуска требуются curl, python, taxonkit >= 0.20 (with ncbi taxdump in ~/.taxonkit), pandas, openpyxl (for excel conversion)

Скрипт создает несколько файлов, результаты хранятся в двух xlsx файлах:
* virus_taxonomy.xlsx содержит полную таксономию всех вирусных находок
* virus_stats.xlsx содержит статистики хитов всех возможных вирусных таксономических групп: медианные percentage_identity, e-value и hit_length. Они посчитаны отдельно для всех таксономических групп (то есть отдельно для всех видов, родов, семейств и т.д.). Так как в выдаче бласта каждому query соответствует только 1 хит (хоть и может быть в нескольких копиях), не нужно думать о том, как классифицировать риды, которые бластанулись на несколько разных организмов. Если бы была такая проблема, можно бы было использовать тулы по типу blobtools. Т.к. нас интересуют медианные значения e-value, p_id и длины хита среди всех прочтений, для рассчетов статистик от каждого прочтения был взят только один хит с наибольшим bit score. Для расчета доли общего числа прочтений, попавших в каждую группу, я использовал два подхода: 1) доля прочтений среди всех прочтений, имеющих хотя бы один хит в выдаче бласта (fraction_of_hits) 2) доля прочтений среди всех прочтений, на которых запустили бласт, в предположении что query_id является сквозной нумерацией прочтений в использованной библиотеке (fraction_of_total_reads_predicted). Скорее всего последний подход избыточен, но на всякий случай пусть будет.
